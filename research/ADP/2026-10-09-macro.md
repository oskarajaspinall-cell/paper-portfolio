# Macro overlay: Automatic Data Processing (ADP) — 2026-10-09

## Assessment
Two channels, pulling in opposite directions. **Chain**: fed funds/short rates → ADP's client-fund interest income (a real earnings line, per the FY2026 10-K) is a tailwind when rates are higher; separately, the 10y real yield → cost of equity → valuation multiple is a headwind for ADP's premium rating (24.7x P/E, price $270.73 vs base-case fair value $228.49, -15.6%) [Likely] **(inference)**.

**Market pricing (facts)**: US 10y real yield (DFII10) 2.92% on 2026-10-07, +0.61pp over 3m; 10y nominal (DGS10) 5.28%, +0.72pp over 3m; effective fed funds (DFF) 3.88%, +0.26pp over 3m (https://fred.stlouisfed.org/graph/fredgraph.csv?id=DFII10, id=DGS10, id=DFF, all 2026-10-07) [Certain]. 2y yield (4.77%) sitting ~0.9pp above fed funds is a proxy for the market pricing further tightening, not cuts (https://fred.stlouisfed.org/graph/fredgraph.csv?id=DGS2, 2026-10-07) [Likely] **(inference)**. Crucially, the fact sheet's own DCF already uses today's 5.28% risk-free rate, so this yield level is already in the -15.6% valuation gap; the surprise that matters is a further move, not the current level.

**Bull**: real yields stabilize/retreat while fed funds stays elevated — eases multiple pressure, float income holds up; fair value re-rates toward the $249 bull case [Guessing]. **Bear**: real yields keep rising (inflation surprise, more hikes) — cost of equity rises further, widening the already-negative valuation gap below $228 [Likely].

**Tilt**: small, toward bear — the move is already largely embedded in today's fair value and ADP's recurring-revenue, low-beta (0.84) profile limits earnings sensitivity to a macro surprise; this nudges the valuation downside case, it doesn't drive the thesis.
